# Methodology and original extraction template

This folder contains the **original blank extraction workbook**:

[`culturally_adaptive_chatbots_review_workbook_v2.xlsx`](culturally_adaptive_chatbots_review_workbook_v2.xlsx)

The workbook records an early saved template dated **16 April 2026**, prior to the documented full-text extraction. It contains the original ten-question research framework, initial screening and extraction fields, response options, and coding lists.

The template is an historical methodology artifact, **not** the final study-level dataset. The extraction fields and coding categories were expanded, reviewed, and refined as the review progressed. In particular, the cultural-formalisation coding was introduced after the initial template, and the original template did not separately code implemented versus discussed mechanisms or measured versus mentioned metrics.

For the 51-study analytical dataset, see [`../data/master_review_analysis_workbook_FINAL_RECHECKED.xlsx`](../data/master_review_analysis_workbook_FINAL_RECHECKED.xlsx). For later source-evidence adjudication, see [`../verification/README.md`](../verification/README.md).

The workbook is preserved under its original filename. A file creation date is evidence of the saved template, not independent authentication of every later coding rule.
